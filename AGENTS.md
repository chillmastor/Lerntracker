# AGENTS.md

Projektregeln für Agenten liegen zusätzlich unter `.agents/rules/` (Projektstruktur, Versionierung, GitHub-Sync).

## Agent skills

### Issue tracker

Issues und Specs liegen als lokale Markdown-Dateien unter `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Die fünf Standard-Rollen (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), als `Status:`-Zeile in jeder Issue-Datei. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: ein `GLOSSARY.md` und `docs/adr/` im Repo-Root. See `docs/agents/domain.md`.
